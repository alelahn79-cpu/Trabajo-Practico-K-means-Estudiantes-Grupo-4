### 📌 **Introducción y Objetivos del Ejercicio**

El presente informe práctico aborda la aplicación del **Aprendizaje No Supervisado** mediante el uso del algoritmo **K-Means** en Python. El objetivo principal 
es explorar un conjunto de datos sintéticos de estudiantes universitarios para agruparlos automáticamenteen **4 segmentos** sin contar con etiquetas previas.
